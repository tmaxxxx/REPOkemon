# Booster 30 ans

Un simulateur d'ouverture de boosters Pokémon de l'extension **30e Anniversaire** (version FR).
Projet perso pour le fun, entièrement codé avec Claude Code.

## Comment jouer

1. Télécharge `Booster-30ans.zip` dans la page **Releases** (colonne de droite).
2. Dézippe le fichier.
3. Double-clique sur `index.html` : le jeu s'ouvre dans ton navigateur.

Rien à installer. Ta collection est sauvegardée dans le navigateur.

## Mention légale

Projet de fan non officiel, sans but commercial. Pokémon et les images des cartes
appartiennent à Nintendo / Creatures / GAME FREAK / The Pokémon Company.
